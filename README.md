## Code not working? Common problems and fixes

**"The referral code field is missing."**
On some app versions the field is hidden behind a small arrow or the words "Referral code (optional)". Tap it. If you still can't see it, register on the website instead, then log in to the app with the same account.

**"I opened the link but the field is empty."**
Browsers with strict tracking protection or ad blockers sometimes strip the code from the link. Type `1888802` by hand. It's only seven digits.

**"It says the code is invalid."**
Check for a space before or after the number and count the digits: it's 1, four eights, 0, 2. The single zero before the final 2 is a digit, not the letter O. Copy it straight from here: `1888802`.

**"I already have an account."**
Codes only work for new registrations. There's no menu in an existing account to add one. If the discount matters to you, the route is to withdraw your funds, delete the account in the security settings and register again with the code. Light traders usually don't need to bother; active futures traders often do.

**"I registered, but I don't see any bonus."**
Most new-user rewards unlock after identity verification (KYC). Finish KYC, then open the Rewards Center. Some tasks only appear after your first deposit.

**"The bonus isn't available in my country."**
OKX adjusts products and promotions to local rules. In some regions certain rewards or derivatives aren't offered. The fee kickback from the referral code is still applied wherever you can trade.

**"I used a different code by mistake."**
Unfortunately the first code entered at sign-up is the one that sticks. It can't be swapped later.

Yes, as long as each person opens their own account with their own identity documents.

**Do I have to deposit to keep the discount?**
No. The fee kickback simply applies whenever you trade. Some bonus tasks do require a deposit, but that's separate.

**I signed up through the app and skipped the field. Can support add the code?**

**Does using a promo code affect withdrawals or limits?**
No. Withdrawal limits depend on your verification level and security settings, not on the code.

**Where can I see my discount after signing up?**
